# 装着ギャラリーの再読込と所有権HUD

対象は10インチiPad横向きMM9C3J/A向けのCSS画面1180×720/820と文字100/125/150%。Linuxの実Chromium/WebKitで操作した結果であり、物理iPadのSafari・外付けキーボード・OS IMEの検証とは区別する。

## 再現と修正

基準`fc7b8ae`は`108da49`から美術検査文書だけを追加した同一の製品コード。新しい6ケースを追加した`2638467`の[実CI 43513408659](https://github.com/mokusatsu/kotobabin/actions/runs/43513408659)で、両エンジンとも4成功・2失敗だった。所有者として最初に開いた画面の収まりだけでは、再読込後の閲覧専用状態を検収できていなかった。

4枠を装着した状態から実際に再読込すると、既存のdocument所有権契約に従って閲覧専用になる。所有権警告がギャラリーと同じヘッダーへ1行追加され、ヘッダー高が172pxから249px/255.6pxへ増えた。720px高の125/150%で文書高がChromium745/801px、WebKit750/811pxへ溢れた。150%では練習ボタンも画面外へ出た。820px高の3文字設定と720px高100%は引継ぎまで成功した。

修正`6bf1d1d`は次のCSS配置だけを変更する。所有権の判定・引継ぎ機構、元の全文、文字サイズと行高、画像の最小寸法、操作領域は変更しない。

- 幅960px以上のホームでは所有権警告をヘッダー下の左マップHUDへ置き、ヘッダーの高さを増やさない。
- 閲覧専用状態の残高HUDをその下へ置き、右コマンドHUDの行間を6pxから4pxへ整理する。長い保存状態文も保持する。
- 下端の案内帯は左のマップ幅へ置き、右コマンドHUDの最終行と横方向に分ける。隠す・切り落とす処理を追加しない。

## 新しい実E2Eの結果

[修正CI 43513985752](https://github.com/mokusatsu/kotobabin/actions/runs/43513985752)、source `6bf1d1dc924afae5380899a8c83882ed09f6ca18`。Chromium job132191206075は6/6成功（13.6秒）、WebKit job132191205938も6/6成功（19.6秒）。

各ケースは表示専用のコスメfixtureで4装着枠を用意し、実reload→閲覧専用表示→文書/操作矩形/scroll検査→ネイティブTab/Enterで「ここで続ける」→所有者・装着内容保持→再度画面検査を実行した。警告と残高、両者と全6地区ラベル、案内帯とコマンドHUDの非重複を実測した。画面キャプチャはこの実E2Eの補助資料であり、操作や矩形検査の代わりではない。fixtureは表示検査用で、全72実績が通常プレイで解除された証拠ではない。

全6組合せで文書高は画面高と一致し、スクロール位置は0。720px高150%のヘッダーは172px、警告下端247.594px、残高上端260px。コマンドHUD下端はChromium705.875px、WebKit715.875pxで720px内に収まった。下端案内帯はx0〜815、コマンドHUDはx833〜1168へ分離した。

通常の全回帰CIは同じsourceの[43513986166](https://github.com/mokusatsu/kotobabin/actions/runs/43513986166)で全5ジョブ成功。正本検査・型・Lint・本番ビルド、33ファイルの単体検査、機能E2E89/89（3.6分）、独立した本番Chromium/WebKit各2/2（各3.7分）、実音声各3/3が成功した。新6ケースは機能E2E89件にも含まれる。

## 検証範囲の留意点

この6ケースは警告/残高と地区ラベルの非重複を検査する。補助画像の720px高150%では、下側の地区ラベルと`world-map-help`案内が重なる様子があり、統括へ報告した。今回の警告/残高の非重複成功を、地図上のすべての案内との非重複成功へ拡張しない。この追加課題の製品修正・受入は本差分に含めない。
