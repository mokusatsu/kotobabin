# M5 ゲームステージの独立受入計画

基準は main `1a8f0e0`。ユーザーの最新指示とAGENTS.mdの全画面ステージ、世界から地区への連続ズーム、操作の空間的反映、確定した実績の個別開封を受入条件とする。M4のカードやページ分割に収まるだけでは新条件の成功としない。以下は実行前の計画であり、合格報告ではない。

| 実ブラウザー経路 | 成功の根拠 | 誤った合格を防ぐ条件 |
|---|---|---|
| 新規HOME→地区選択→拡大→戻る | 世界の全6地区が同時表示され、native Tab/矢印/Enter/Escで対象地区全域へ移る。地区ID・選択・拡大前後の幾何を照合 | 地区名や数値だけの別カードに切り替える表示を代替にしない。カメラの移動・戻りを確認 |
| 更地→計画→建築 | 実入力による資材生成・到着から、同じ地区の更地が計画中の足場、完成した段階1建物へ変わる | 保存済み段階値とマップの対象地区ノードを両方確認。全体件数の増減だけでは不可 |
| 投資とマップ | 荷づくり台・班・店・鉄道・連携・研究の有効操作の成立と対象地区の視覚ノードまたは外観変化を照合 | コインだけ減る、数値だけ増える、他地区だけ変わる状態は不可。失敗・取消・再送は外観を増やさない |
| 90秒→結果ステージ | 実際に完成・配達した便だけを終了し、得点から封印した実績、個別開封、まとめへ進む | 実DBの今回の解除ID集合と表示IDを照合。架空の実績・重複付与・抽選確率・レア度を導入しない |
| 個別開封のキー操作 | Enter/Spaceで実績を一つずつ提示、Escで今の演出短縮、Sで残りをまとめる。短縮後も同じID集合と保存 | キー連打・再描画・結果再訪で解除や報酬を再付与しない。演出を飛ばすと報酬が消える状態を不可 |
| 機器・文字・動き | 1180×720と1180×820、100/125/150%で世界・地区・設備操作・結果の全操作がviewport内。reducedMotionでも意味・到達性を保持 | overflowで隠す、文字倍率を戻す、操作をpointerだけにする変更は不可。実機Safariの検査と区別 |

状態の準備は原則として実入力と公開画面操作を使う。高額な後半投資の保存準備が必要な場合は、既存の純粋な経済コマンドと現行保存コーデックによる有効な状態を生成し、実IDBに保存する独立ケースとして明示する。主経路の最初の建築と実績は偽の獲得を注入しない。保存・再読込・所有権など既存の実IDB試験は維持する。

通常E2Eの全件を残し、ゲームステージへの正当な変更に合わせてセレクターと結果の進行操作だけを更新する。viewport矩形・scrollWidth/Height・フォーカス・フォントの検査は弱めない。以前の独立レビューはM4の履歴として保存し、互換更新した既存シナリオと、新しい履歴なし担当者のM5レビューは区別する。ブラウザーは承認されたCIで実行し、画像だけで代替しない。

## 追加された配達プレイ場面の条件（D015）

タイピング自体も全画面のゲーム場面として組み直し、完成した荷物が発送・移動・到着する。既存のHTMLや情報カードの積み重ねに演出だけ足した状態を新条件の成功に数えない。確定した文字・完成・発送の事実と、実際の街の到着差分を表示に結び付け、表示だけのタイマーから資材や到着を発生させない。

追加の実E2Eでは、ネイティブ入力5語と満載発送から輸送中の荷物を捉え、実際の到着差分に応じた位置変化、輸送中も6語目を入力できるフォーカス、確定済み事実の再描画による二重演出防止を検査する。入力を一時停止したまま街の実時間を進め、待ち資材0・実保存の到着・到着表示が一致し、タイピングの残り時間と得点は停止前と同じであることを要求する。動きを減らす設定では移動中の離散表示と、実到着後の終点表示を検査し、未到着を到着済みに見せない。長い語・別綴り・文字倍率による入力位置とviewportの厳密検査は維持する。

高額設備の別E2E用fixtureは、資材・コイン・段階・報酬を直接代入せず、CityEconomyの確定経済事実と公開コマンドだけで2つの街を育て、再出発で設計図を取得する。この準備は実キーボード入力ではなく明示したドメインfixtureであり、初回建築・実績・荷物移動の主要経路に置き換えない。実UIの荷づくり台7→8、配送班10→11、店舗7→8、鉄道、連携、研究の購入後はSVGの実寸・経路・図形の変化を調べ、data属性や数値ラベルだけの変化で合格しない。新しいコマンド台帳の内容と経過時計を購入前保存へ再適用し、購入後のコイン・在庫・予約・研究・生成と到着の保存則も照合する。
