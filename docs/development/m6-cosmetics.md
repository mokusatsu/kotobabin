# M6 コレクションと装飾

## 実装した動作

装着の選択を称号・額縁・飾り・ホーム背景の独立した4種類とし、それぞれ非表示を選べる。`homeBackgroundId` は現行形式へ加えた任意項目で、未指定は背景なしとして扱う。新しい状態では4種類ともnull。装着アクションは所有と種類を検査し、夕景を飾りとして装着したり、アルバムを装備したりできない。報酬獲得による自動装着はない。

現行保存データに既に含まれるpostcardId・boardId・albumId、および旧UIでornamentIdに保存された夕景の値は削除・移動しない。これらは新しい装着UIへ露出せず、夕景を飾りとして適用しない。現行形式の読み込み検査は、それらの所有・種類も検査しつつ、新しい背景項目の省略を受け入れる。過去版を読み替える移行処理は作っていない。

全40報酬についてマニフェストの参照先を小さな明示的パス表へ転記し、原画・SVG・紋章・共通枠を実際に合成する。巨大な制作マニフェスト自体は実行時へimportしない。謝辞は指定のDOM文とし、制作中という代替表示を除いた。未取得でも鑑賞できるが、装着できるのは所有する対応種類だけ。私的なプレビューID・ページはUI内だけに保持し、鑑賞操作で装着・得点・資材・設備・報酬所有を変更しない。

コレクションの「眺める報酬」ネイティブselectと決定ボタンから、全報酬へキーボードで直接移れる。各カードにも鑑賞ボタンを置く。絵葉書・アルバム・台紙・記念切手は装着操作を要求しない。装着中はチェックとDOMラベルで示す。

系統台紙の詳細は、仕様が認める可変高の2列／1列DOMカード方式を使い、1系統の切手6枚と名称を表示する。小さい表紙サムネイルには紋章と完成状態だけを置き、6切手を縮小して詰め込まない。6件の確定をもとに箔を適用する。未公開の隠し切手は名称と固有図を露出しない。第1集完成はA〜Hの8ページ、全72完成は12系統の12ページ。24枚・60枚アルバムは、I〜Lを含む収集にも対応した12系統の閲覧ページを持つ。総数48の記念台紙は独立した紋章と名称であり、第1集完成と同一視しない。

所有する額縁・飾りをホーム／手帳の専用ギャラリーへ反映する。夕景パネルはホームの独立領域だけへ置く。地図・地区・ゲーム・練習・導入へ原画を適用しない。ホームの非空ギャラリーはヘッダー内の専用セルを確保し、額縁240×160、飾り256×64、夕景320×80を配置する。地図と操作ドックへ重ねない。額縁内の内容は透過内窓へcontainで収め、名称や条件はDOMに残す。

## 検証と適用範囲

`npm run build`、型検査、変更ファイルのESLintが成功。`tests/profile/cosmetics.test.ts`、`tests/ui/reward-art.test.ts`、既存のprofile restore／achievementsを合わせた54テストが成功した。4種類の独立性・解除・所有と種類の拒否・事実の不変性・現行バックアップ往復・任意背景の省略・既存値の保持・全参照パス・8／12ページの区別を検査する。

`tests/e2e/cosmetics.spec.ts` は1180×820で100／125／150%の非空ギャラリー、実Tab・F2・矢印・Enterによる鑑賞、表示パネル全巡回、6枚・箔・8／12ページ、鑑賞前後の装着不変性、未所有プレビューを検査する。フィクスチャは実際のGameSessionから得た入力事実と正本の実績reducerで72件を確定する。街の発展段階等は明記した合成テスト入力であり、利用者が購入操作で到達した記録ではない。unlockや報酬所有を直接追加しない。

開発診断としてローカルVite `http://127.0.0.1:5196/` に対し `npx playwright test --config /tmp/cosmetics-playwright.config.ts` を実行し、4ケースが41.8秒で成功した。診断成果物は `/tmp/cosmetics-playwright-results`。最初に再現した下端ギャラリーとドックの重なりは専用ヘッダーセルへ修正した。150%でドック高599.17pxがステージ高611.20px内に収まることを実ブラウザーで測定した。

このローカル診断は正式なSites／GitHub CIプレビュー受入ではない。この作業ブランチの基点には夕景原画など未統合の資材があり、該当画像は404で、診断は宣言された寸法での配置・操作の確認に限られる。正式プレビューに関する制約の連絡を受けてローカルサーバーを停止した。全資材を統合した承認済みプレビューでの画像読込、実iPad、独立sakuraiレビュー、製品受入は親作業の検証に残す。マージ・push・公開は行わない。

別途 `3995a85` はネイティブselectが再描画でフォーカスを失う問題への独立修正。DOMの安定IDと存在する選択値を保存し、`preventScroll:true` で復元する。viewerの変更とは分離して提出した。これ以降profile/achievements.tsは別の性能修正担当へ引き渡して変更していない。
