# 保存版8の地形・港合成と最小表示の正本照合

## 結論

基準はmain `d645d9e1883b53a93af4ba14541ce78aaa12fae3`、配信先は保存版8。同版の配信source `3c636ff92ec2c83c71653459ab857e2d2d874976` と基準commitのsrc/public/tests差分は0である。専用worktree `/workspace/work/m8-terrain-audit`、branch `audit/m8-terrain-art` で読み取り検査した。

地形3原画とruntime、港5段階の固定点・静止合成、800×500の資材単位表示に、新たな描き直しを必要とする明確な美術不具合は認めなかった。従来の色診断も再現した。一方、**実UIで全地図を800CSS px未満へ縮小し、正本指定の表示切替を行っていない不足を実ブラウザー測定で確認した。** 親がgame stage内の6地区HUD＋選択地区図への切替を修正中である。修正後の実E2Eは本報告の合格へ含めない。

色診断だけで厳密な連続幾何を証明できないことは検証方法の限界であり、それだけを実画像の新しい不具合とは呼ばない。原画のRGB全画素一致、3背景の水色判定マスクの完全一致、独自の誤差閾値を新たな必須条件にしない。旧不採用候補の30px級ずれや、alpha0に隠れたRGBを現物の欠陥として復活させない。

## 原画・runtimeの現物検査

3点のPNGとWebP、計6ファイルを直接読み、全て3200×2000 RGBで透過なしと確認した。現在のnativeは川沿い1585×992、海辺1586×992、高原1585×992。全キャンバスLANCZOS正規化を再計算すると現PNGのRGBと一致した。これは変換来歴の再現確認であって、全runtimeにRGB一致を要求するものではない。切り抜き・岸線マスク・閾値による画像変更は行っていない。

| 現runtime | SHA256 |
|---|---|
| riverside | `82ae0be48c947abc17744c07cdedec8350fb9d00b56e8de995df76f36741125d` |
| seaside | `84e2de3db6bf26863a3ff243dd660ff4b498b2084cabc5f6af2ee4541eeec7a0` |
| highland | `a3e9974558fe38b9581a1a4c6eda65dc45706c35ff660e5c7960c0d839c50f38` |

既存診断と同じ `B>1.06R && G>1.03R` が3画素連続する最初の位置を、水色の近似検出として再計算した。全2000ソース行・12点・港矩形・24map_px経路保護域を読み、次を再現した。新しい閾値を正本へ追加していない。

これらの差を新たに「2.2pxまでは必ず合格」などと許容値にしない。水彩色・ラスタ補間・有損符号化で分類境界は変わり、正本の接続位置と色の開始位置は同義ではない。現在の診断と目視は18px陸地確保・共通配置との整合を支持するが、分類マスクの差だけから幾何違反と断定できない。反対に、色診断が0/18を示しただけで全形状の数学的証明を完了とも扱わない。

港5段階は全て1024×768、safe外alpha0・店舗予約矩形alpha0だった。固定接点のalphaは順に253/253/253/254/253、先端は251/252/172/255/251で、全段階に絵が存在する。alpha172は描画ありで、勝手に255を要求しない。`src/ui/district-map.ts:33`〜38の原画配置と `src/ui/city.ts:76`〜81のworld変換を合わせると、source→map倍率は264/1024、配置はanchor−(132,165)となり、正本の名目接点へ数式どおり写る。

3地形×港5段階の15静止合成を正規位置で確認した。屋根の張り出しと桟橋は水際を越える一方、非桟橋の床・柱が水面へ新たに接地する様子は認めなかった。これは目視した部位についての資材単位確認で、全alphaから床・屋根を自動分類した証明ではない。全30地区のモチーフや全設備状態の最終受入へ範囲を広げない。

runtime単体および6地区段階5を置いた静止資料を800×500の色・グレーで確認した。川沿いの丸い木、海辺の松・草、高原の山・針葉樹を識別でき、中央・経路・港の平地を植生が塞がない。これらはUI・状態を伴わない検査用合成であり、ゲーム画面のE2E画像ではない。測定JSONと静止資料は専用worktreeの `work/m8-terrain-audit/` に隔離保存した。
