# 街の解放条件と段階別コスト

## 街を増やす条件

| 街 | 開始・出発条件 | 出発時に支払う料金 |
|---|---|---:|
| 第1の街 | 川沿いの街から開始 | 無料 |
| 第2の街 | 第1の街で全6地区がLv.3以上、かつ、その街への累計到着資材が100,000以上 | 無料 |
| 第3の街 | 第2の街で全6地区がLv.3以上、かつ、その街への累計到着資材が120,000以上 | 無料 |
| 第4の街 | 第3の街で全6地区がLv.3以上、かつ、その街への累計到着資材が144,000以上 | 無料 |

第2の街からは川沿い・高原・海辺のいずれも選べる。到着資材の集計は各街でゼロから始まり、建築に使った到着済み資材も累計に残る。第3の街へ出発するまでに必要な到着量は、最初の2街で合わせて220,000資材。

出発資材、建築費、街の設備、景観の単価には、街を作った順に **1倍 → 1.2倍 → 1.44倍 → 1.728倍 → …** を適用する。第nの街の価格は「第1の街の価格 × 1.2の(n−1)乗」の端数を切り上げた整数。まとめ買いは1個ずつ切り上げた単価を合計する。以前の街に戻ったときは、その街の番号で計算する。研究ランクと設計図は全街で共有する。

## 地区の開通と建築費（第1の街の基準額）

Lv.1〜5の金額は、**その地区の在庫から、その段階で消費する資材**。開通条件は、その街の全地区のLv合計で判定する。条件を満たすと無料で開通し、Lv.0から最初の建物を建てられる。建築にコインはかからず、各Lvの人や煙などの演出も建築と同時に解放される。

次の街に進むための最少建築費は**第1の街51,540、第2の街61,848、第3の街74,221資材**。第1の街で全6地区のLv.1〜3に使う資材は49,140。港町を開くには先の5地区で合計Lv.16が必要なので、最少額で進めるには住宅地をLv.4にして2,400資材を追加する。

## 階段状か

| 比較するもの | 判定 | 根拠 |
|---|---|---|
| 同じ地区の建築Lv | 毎段階で上昇 | 前段階の5倍、4倍、4倍、3.75倍。全地区を完成させる建築費の約74%が最後のLv.5に集中する。 |
| 同じLvで比べた地区間の建築費 | 開通順に上昇 | 同じLvなら、直前に開通する地区のちょうど2倍。 |
| 次の地区が開くまでの最少累計消費資材 | 毎段階で上昇 | 0 → 180 → 540 → 1,860 → 6,900 → 21,780。個々の建築の順では、住宅地Lv.2の150から、新たに開いた商店街Lv.1の60へ下がることがある。 |
| 同じ景観アイテムのLv | 上位Lvで大幅に上昇 | 基本価格の1、2、100、2,000、30,000倍。街全体の景観総額には地形ごとの差がある。 |
| 次の街への出発 | 街ごとに上昇 | 必要な累計到着資材は100,000 → 120,000 → 144,000。各街で6地区すべてLv.3以上が必要。 |

## 店舗収益と景観の購入時間

コインの供給源は店舗の時間収益と配達報酬。店舗は資材を消費せずに稼働し、離席中も1回の復帰につき最大8時間分を精算する。資材はすでに輸送待ちの分だけが離席中も届く。到着1資材につき通常2コイン、共同配送の購入後は3コインが入る。たとえば通常報酬のまま第1の街の出発条件10万資材に届くと、配達報酬だけで通算20万コインになる。途中の支出はここから差し引く。

第1の街で輸送待ちを空にし、商業収益研究・観光便なしで60秒進めたときの店舗収益を比較した。建物のLvが1上がるごとに各店舗の収益が2倍になり、各地区の店舗数が10・25・50軒に達するたびに、その地区の全店の収益がさらに2倍になる。

| 街の状態 | 毎秒のコイン | 花壇Lv.1（15コイン） | 花壇Lv.5（450,000コイン） |
|---|---:|---:|---:|
| 住宅地Lv.1、1軒 | 0.1 | 2分30秒 | 約52日 |
| 住宅地Lv.3に10軒、商店街Lv.2に5軒 | 10 | 1.5秒 | 12時間30分 |
| 住宅地Lv.4、ほか5地区Lv.3、各1軒 | 25.6 | 0.59秒 | 約4時間53分 |
| 同じ建物で各10軒 | 512 | 0.03秒 | 約14分39秒 |

各時間は、残高ゼロから該当する1回の購入代金が貯まるまでの換算値。建物・店舗数と収益が一定で、配達報酬を含めず、離席中は1回8時間の精算上限内で定期的に復帰する場合の目安となる。

第1の街の川沿いで、10種類をすべてLv.2まで飾るには732コイン、すべてLv.5まで仕上げるには7,833,132コインかかる。毎秒512コインなら全購入額は約4時間15分、毎秒25.6コインなら約85時間分の店舗収益に相当する。毎秒512の街で8時間分の離席報酬を受け取ると14,745,600コインになり、全景観を購入できる。

荷づくり台・配送班・店舗は所有数に応じてすでに指数的に値上がりし、購入が資材生産や収入に直結する。第1の街の住宅地で2軒目の店は29コイン。Lv.1では毎秒0.1コインの増収で、購入額の回収には4分50秒かかる。観光便の10万コインは、購入直前の収益が毎秒25.6なら約65分、512なら約3分15秒に相当する。景観のLv.4・5は出発条件に含まれず、街に戻って仕上げることもできる。

設計図で買う研究はコインの自動収入から独立している。実プレイで比較する際は、景観Lv.1の初回購入時期、街の出発時点の景観Lv分布、出発時に残っているコインを指標とする。

第1の街の基準額は、3地形の建築90段階と景観150段階について購入処理で検証した。街番号による倍率は、出発条件の境界、設備・景観の購入、以前の街を再訪した際の価格で検証した。
