# I系統切手 — 制作候補報告

対象は `stamp_i01`〜`stamp_i06` の6 ID。正本 `visual_resource_manifest.json` の各 `visual_brief`、`achievement_catalog.json` のモチーフ・識別点、`resource_implementation.md` のstamp仕様を読み、既存F01原画を目視して暖かい水彩・ガッシュ、クリーム・黄土・緑・赤茶の画風を合わせた。共有マニフェスト・台帳・UI・公開状態は変更しない。

## 制作と保存

実際のimagegenを6回呼び出し、透過背景の独立した新規原画を制作した。既存原画は画風の目視参照だけで、生成器への画像参照・編集入力には使っていない。各1回の生成を選び、不採用生成や図柄の再編集はない。正確なプロンプト、`transparent_background:true` の生成方法、原生ファイル名を `public/assets/originals/production/family-i/requests.json` に残した。

全6点の原生1254×1254 RGBAを無変更で `public/assets/originals/stamp_iNN.generated.png` へ保存。ImageMagickで原生キャンバス全体を448×448へ縮小し、512×512透過キャンバスの(32,32)へ配置した。トリミングや図柄の描き直しは行わない。指定PNG原画は `stamp_iNN.png`、実行時候補は `public/assets/achievement_stamp/stamp_iNN.webp`。lossless WebPのアルファと紙色合成全画素がPNGと一致することを検査した。

再現用 `production/family-i/export.py` と `measurements.json` に原生・実行時SHA256、出力バイト数、寸法、アルファ境界、PNG/WebP一致を保存。6点とも512×512 RGBA、安全域32..480内、論理アンカー(256,256)。原生の外周には低アルファの粒子が接する場合があり、生成器内部の未切断までは証明しない。

## 最小表示と未検証範囲

`minimum-size-verification.png` は原画72pxを紙色へ合成した彩色・グレースケール比較。制作担当が静的に目視し、I01の単独三角屋根、I02の横長の二軒とアーチ、I03の三角配置、I04の円い空地、I05の高い塔、I06の太い門の輪郭を区別した。I01の芽、I04の各施設、I06の遠景の細部は原画では明確だが72pxでは細部になる。

共通枠SVG用のrsvg-convertがこの実行環境にないため、この資料は枠合成ではなく原画単体の検査に限定した。生成原画の代わりにSVGや記号を納品していない。これは制作担当の静的単体検査であり、独立した美術最終受入、実ブラウザーE2E、手帳・結果での状態合成、iPad実機確認、全72枚の比較、マージ・公開・製品完成を意味しない。
