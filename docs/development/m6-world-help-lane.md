# 世界図の案内と下段地区ラベル

基準は再読込HUD修正済み`f3ce5e2`。元の実E2E source `6bf1d1d`、[CI 43513985752](https://github.com/mokusatsu/kotobabin/actions/runs/43513985752)は、全4装着の再読込とネイティブTab/Enterによる所有権引継ぎをChromium/WebKit各6ケースで成功した。その実操作に付随する1180×720・文字150%の画像では、`world-map-help`が下段地区ラベルの状態文へ重なっていた。従来の非重複assertは警告・残高・案内帯対コマンドHUDを対象としており、help対地区ラベルまでは検査していなかった。成功範囲を拡張して扱わない。

同じ状態の上段ラベル下端は約469px、下段ラベル上端は約569pxで、間に約100pxの帯がある。約38px高の案内をworld-stageの64%位置へ移し、上下約30pxを取る。文字、全文、画像寸法、地図の座標・倍率、所有権やゲーム進行は変更しない。

また、この高さでは駅前ラベル下端が約693px、下端案内帯の上端が683pxで交差する可能性がある。高さ760px以下でギャラリーがある場合だけ、駅前ラベルを地図下端から8px内側へ配置する。地図や地区の絵を動かす修正ではない。820px高では既存位置を保持する。

この差分はCSSと本記録だけ。統括の同一ソースへ統合後、別担当がhelpと全6地区ラベル、警告、残高、案内帯、コマンドHUDの矩形を既存の実E2Eへ追加して公式CIで検証する。ローカルの代替サーバーや、画像だけによるE2E代替は使っていない。**本稿の時点で修正後の合格は未確認**。
