# 開発比較の専用入口

`/dev.html` は技術仕様§13の比較用画面。通常版のメニューには追加しない。画面・書き出しには開発用であることを表示し、AppRuntime/ProfileRepository/実績・経済の保存処理をimportしない。IndexedDB、localStorage、通常成績へ書き込まない。

## 操作と適用範囲

- 固定の収録960語、seedによる3コース、またはカスタム表示・読み（各40文字）を選ぶ。
- 荷物数、残りms、IME入力確認が必要な停止状態、完成/手動配達/満載/誤打/救済/期限を指定する。
- 設定は停止中だけ編集でき、「条件を再生して比較を作り直す」で新規GameSessionへ適用する。入力再開は別の明示操作。実入力はInputAdapterで確認する。IME確認の半角aは採点しない。
- 荷物と得点はGameSessionの公開input/deliver/skip/tickを再生して作る。最大個数の荷物は正式ルールどおり直ちに満載配達となり、保持中の数は0になる。残時間だけを再現する場合も時計開始に必要な準備入力を操作記録へ残す。
- 比較用GameSessionの制限時間・基準1打点・最大荷物数と係数/分母・復習語数を調整できる。GameSessionを数値で直接書き換えない。通常のconstructorは正式既定90000ms/10点/5個/分母5/復習10語を使用する。
- 日本語名と識別子の全13項目は対応表の2ページに表示する。描画/音/通知等の値は専用入口では編集せず、接続先と初期値を表示する。まとめの切手見本3枠は、後続ユーザー指示による全件の個別開封を制限しない。
- 「事実と書き出し」は実SessionFactと実得点を表示する。開発JSONは条件・規則・準備/実入力操作・事実・snapshotを含むが、通常のバックアップ形式ではない。

キーボードのTab/Enterで全操作ができ、ゲーム入力のEscまたはblurで停止する。値の変更で進行中の採点条件を変えることはない。OSのIME実機試験を開発条件の注入で代替したとは扱わない。

## 検証
