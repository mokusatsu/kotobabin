# 節目報酬4原画 — 制作候補報告

対象は `reward_celebration_postcard`、`reward_evening_panel`、`reward_first_collection_stamp_art`、`reward_collection_stamp_art`。正本マニフェストの図柄・プロファイル、実績カタログの対応報酬、design_tokens、rendering_rules、資材実装仕様および既読の5代表画面を参照した。前2点は不透明RGB、記念切手2点は透過RGBAとして実際のimagegenで各1回生成した。文字・数字・謝辞・名称・施設完成表示・解除状態を絵へ入れていない。

## 生成と保存

正確な4プロンプトと `transparent_background`、返却パスは `public/assets/originals/production/milestones-m6/requests.json`。全返却原生を同ディレクトリーの `*.attempt-01.png` と、無変更の `public/assets/originals/<ID>.generated.png` に保存した。不採用生成・編集はなく `rejects.json` は空配列。原生のSHA256は `native-file-hashes.json` に保存した。

生成結果は祝賀絵葉書1586×992 RGB、夕景2172×724 RGB、記念切手各1254×1254 RGBA。水彩・ガッシュのクリーム、黄土、森林緑、赤茶を共通とする。祝賀ではアルバム、左右の花束と封筒、上の三角旗、小さな遠景の人々を確認した。第1集は手前の開いた鞄・封筒、中央のアーチ橋、郵便局から丘の展望台へ抜ける道。総集は見開き本の上の川・橋・住宅・店・工房・駅・港・丘と連続する道で、第1集と主形・視点を分けた。

## 正規化と検査

`production/milestones-m6/export.py` で原生キャンバス全体をcontainし、比率を維持して規定キャンバスへ配置した。切り抜き、マスク、アルファ閾値処理、描き足し、非等方変形はない。整数丸めによる1px差は計測値へ記録した。

| IDの末尾 | 出力・論理アンカー | 原生全体の縮小・配置 |
|---|---|---|
| celebration_postcard | 1600×1000 RGB・(800,500) | 1439×900へ縮小、(80,50)、残りは紙色#F5F1E7。描画が安全域80..1520/50..950内 |
| evening_panel | 1600×400 RGB・(800,200) | 1200×400へ縮小、(200,0)、左右各200pxを不透明紙色#F5F1E7 |
| first_collection_stamp_art | 512×512 RGBA・(256,256) | 448×448へ縮小、(32,32)、残りは透過 |
| collection_stamp_art | 512×512 RGBA・(256,256) | 448×448へ縮小、(32,32)、残りは透過 |

夕景は4:1を明記して生成要求したが返却は3:1だった。全景を切らず1600×400の4:1へ収めるため、絵の横幅は出力の75%となる。大きな夕日と長い雲、遠い屋根、灯る窓は残るが、全面を夕景で埋めるfull-bleed画像ではない。統合担当の指示でこの候補を保存し、最終受入で余白を確認する。プロフィールの安全域40..1560/20..380は主題の配置目標であり、空と遠景屋根の背景画素は上下の端まで達する。

正規化PNGは `<ID>.normalized.png`、指定PNGは同内容の `<ID>.png`、lossless WebPは正本通り `public/assets/milestone_raster/<ID>.webp`。全4点の寸法、モード、アンカー、変換、原生・正規化・WebPのSHA256、バイト数は `measurements.json`。不透明2点はアルファ255、切手2点の全出力アルファは32..480安全域内。全4点でPNG/WebPのアルファ全画素と紙色合成全画素が一致した。

隠れたRGBは描画欠陥の根拠にせず、`*.paper-inspection.png` の不透明紙色合成を目視の正本とした。原生の端の低アルファ粒子が生成器内で未切断かどうかまでは、出力安全域検査で保証しない。

`minimum-size-verification.png` は祝賀160×100、夕景320×80、切手72×72の彩色・グレースケール。アルバムと花束、太陽と横雲、鞄とアーチ・登り道、見開き本の輪郭を両方で区別した。夕景は最小幅320pxのうち絵が240px、紙色余白が左右40pxずつとなる。太陽と屋根は読めるが、窓の細部は小さい。
