# 絵葉書C〜G — 制作候補報告

対象は `postcard_c`〜`postcard_g` の5点。マニフェストの個別visual_brief・postcard profile、実績正本の5報酬、design_tokensと代表5画面、既存 `postcard_a/b` を参照した。花屋・駅前・図書館・工房・河岸の個別の場面を制作し、一般的な風景への置き換えは行っていない。C〜G系統を3件解除した際の鑑賞用装飾報酬であり、効果・解除条件・表示状態は原画へ含めない。

## 制作・保存・書き出し

実際のimage_genを5回、最終原画ごとに独立して呼び出した。すべて `transparent_background:false`。既存絵葉書A/Bと代表画面は画風の目視参照のみで、生成器への画像参照入力はない。正確なプロンプト、生成ファイル名、背景指定、選定状態を `public/assets/originals/production/postcards-cg/requests.json` に保存した。再生成・編集・不採用候補はない。

原生1586×992 RGB PNGを無変更で `public/assets/originals/postcard_x.generated.png` へコピーし、生成元と全バイト一致を検査した。原生キャンバス全体をPillow LANCZOSで1600×1000 RGBへ正規化した。ネイティブ比率と指定8:5との差を合わせる0.075662%の縦横比補正があり、`measurements.json` のscale_x/scale_yへ記録している。切り抜き、トリミング、余白追加、マスク、絵の描き直しはない。環境や床・空・壁は端まで描かれた一枚絵で、主役は内側に配置される。

指定PNGは `public/assets/originals/postcard_x.png`、実行時候補は `public/assets/postcard/postcard_x.webp`。全5点で1600×1000、不透過RGB、論理アンカー(800,500)、主役の配置基準safe_rect=(80,50,1520,950)。風景の周辺部までsafe_rectへ収める仕様ではない。lossless WebPを保存し、正規化PNGとの全RGB画素一致を検査した。原生・PNG・WebPのSHA256、ファイルサイズ、寸法、モード、変換方法を同productionフォルダーの `measurements.json` に保存し、`export.py` から再現できる。WebPは各約2.4〜2.6MBで、配信サイズの最適化はこの制作候補の変更に含めない。

クリーム・木の黄土・森林緑・控えめな赤茶を軸に、A/Bの柔らかな水彩・ガッシュと親しみのある町の描写を合わせた。文字・数字・名称・UI・状態印・外枠は焼き込んでいない。Dの二針時計、Gの荷札は物理的な場面要素である。

`minimum-240x160-color-gray.png` は、依頼の240×160比較セル内に比率を保った240×150の絵を置いた彩色・グレースケール比較。`minimum-spec-160x100-color-gray.png` は正本の最小160×100での比較。両方を制作担当が目視した。花束を包む両手、配達自転車と庇の遠近、左右本棚と中央本、未完成／完成箱、河岸の積み箱と橋を区別できる。160×100ではCの水滴・指先、Dの車輪の細線、Eの背表紙、Fの削り跡、Gの舟の荷物は細部になり、静的な大きな形を読む用途に限られる。
