# H〜L系統の絵葉書 — 制作候補報告

対象は `postcard_h`〜`postcard_l` の5点。AGENTS.mdと制作資料README、manifestの各visual_briefとpostcard仕様、achievement_catalogの5報酬、design_tokens、5代表画面を確認した。既存postcard_a/bのRGB原画を目視して、クリーム、森林緑、控えめな朱色、黄土の木材、左上の柔らかい光、水彩・ガッシュの村の挿絵に合わせた。

## 実制作と保存

実際のimagegenを5回呼び出し、各1回の独立した新規生成を選択した。すべて `transparent_background:false`。5枚とも背景まで描いた不透明な場面画である。画像の編集・不採用生成はない。参照画像は目視だけで生成器には渡していない。正確な全プロンプトと原生ファイル名は `public/assets/originals/production/postcards-hl/requests.json` に記録した。

原生ファイルを無変更で `public/assets/originals/postcard_x.generated.png` に保存した。H〜Kの原生は1586×992 RGB、Lは1568×1003 RGBで、全点にアルファチャンネルはない。指定PNG原画を `postcard_x.png`、実行候補を `public/assets/postcard/postcard_x.webp` に置く。

## 書き出しと目視

再現用export.pyは原生キャンバス全体をLANCZOSで1600×1000へ正規化する。クロップ、マスク、閾値処理、描き足し、余白パディングはしない。全画像がRGB、1600×1000、アンカー(800,500)で、lossless WebPのデコードRGB画素が指定PNGと完全一致することを検査した。原生・PNG・WebPのSHA256、バイト数、原生寸法、正確なX/Yスケールはmeasurements.jsonに記録する。

原生と8:5規定の比率差を全キャンバスのX/Y縮尺で補正している。H〜Kの比率補正は約0.076%、Lは約2.35%。Lには小さい非等方変形があり、完全な等方拡大ではないことを受入時の制約として明示する。内容を切り取って検査を通してはいない。

| H | 丘の木の展望デッキと大きな双眼鏡、手すり、中央を曲がる道、下方の川と屋根、広い空 |
| I | 少し上からの設計机。中央の線だけの街区図、手前の家模型、脇の定規と鉛筆、奥の巻いた図面 |

主題は安全域(80,50)〜(1520,950)の内側へ配置し、地面・壁・空等の背景は端まで続く。外枠・名称・数値・説明札・UI状態は描き込まず、Iの図面は建物の線のみで注記・寸法数字を含まない。

`minimum-size-verification.png` は各240×160検査タイル内に8:5原画を240×150で置き、彩色とグレースケールを並べた。制作担当が目視し、Hの高所の双眼鏡、Iの平面図と模型、Jの6地域と太い道、Kの3展示台と歯車、Lの棚・椅子・斜めはしごを区別した。Jの施設細部やLの小模型は縮小時には細部となる。仕様上の最小160×100も `spec-minimum-160x100.png` に彩色・グレースケールで出力し、5場面の主題の差を目視確認した。施設細部を全て読めるとは主張しない。

これは静的な制作候補の単体確認で、独立した美術最終受入、実ブラウザーE2E、手帳・ホーム・結果での表示確認、iPad実機評価ではない。共有台帳・レジストリ・UI・仕様を変更せず、push・公開も行っていない。
