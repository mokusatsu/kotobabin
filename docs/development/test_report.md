## ブラウザー検証の阻害要因

公開先はGitHub PagesからChatGPT Sitesへ変更された。管理されたSitesプレビューの `sites-preview start /workspace/kotobabin` がrelay port4173のタイムアウトで停止し、共有ブラウザーの初期化も `gaas-browser node_repl sandbox cannot be disabled` で失敗したことが統括担当から報告された。代替サーバーでこの基盤制約を迂回せず、ローカル実ブラウザーQA・スクリーンショット検収は未実施とする。

`tests/e2e/game.spec.ts` に、ネイティブ入力→手動配達→90秒終了→同一順序の再挑戦、誤打時の確定点維持、一時停止時間除外、狭幅での開始前案内の3テストを追加した。CI用に作成したが、この環境で実行できたとは報告しない。デスクトップのホーム・本編・結果と狭幅ホームのスクリーンショット出力も指定しており、CI成果物へ保存される予定である。画像の出力だけでは人間または独立担当による視覚検収の完了にはしない。
