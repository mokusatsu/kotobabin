# ことば便 出題資材仕様・全960件

文書版4.0／内容版2.0.0／出題スキーマ版2.0.0／入力規則版romaji-1.0.0

ことば便は、日本語の語・短文960件を収録する。本書は全原稿と編集基準、固定集合、導入・試作用の選定、実装に渡すデータの使い方を定める。得点や実績の体験は[ゲーム体験仕様書](game_experience.md)、入力経路・IME・出題計画は[技術仕様書](technical_specification.md)、画面上の扱いは[画面設計](screen_design.md)を参照する。

## 1 納品する資材

出題の正本は[words.json](../data/words.json)とする。全件で表示、読み、安定ID、コース、分類、難度帯、入力要素、基準長、複雑度、校正状態を設定済みで、空の仮原稿は含まない。全件表は同じJSONから生成する。

| ファイル | 内容 | 実装での用途 |
| --- | --- | --- |
| [words.json](../data/words.json) | 960件の全原稿、5つの固定集合、導入3件、試作30件の参照ID | 出題・図鑑・練習の共通データ |
| [words.schema.json](../data/words.schema.json) | JSON Schema Draft 2020-12、出題スキーマ版2.0.0 | データ構造の検査 |
| [romaji_rules_v1.json](../data/romaji_rules_v1.json) | 単文字・拗音・外来音の138キーと「ん」「っ」の規則。規則スキーマ版1.0.0 | 受理経路と基準長の生成 |
| [legacy_word_index_v1.json](../data/legacy_word_index_v1.json) | 初版240件のID・表示・読み・コース・分類・基準長の固定参照 | 旧語とE04の対象集合を照合 |
| [validate_content.py](../tools/validate_content.py) | 標準Pythonだけで動く検査器 | 構造、件数、重複、規則、派生値、帯、固定集合、旧語、参照IDの再確認 |

ファイルはUTF-8のJSONとMarkdownを使用する。表示語から実行時に読みを推測せず、必ず収録済みのreadingを使う。editorialNoteは制作・校正用の注記であり、ゲーム中へ常時表示する項目ではない。

## 2 原稿と難度の考え方

身近な語を短く打ち切る経験から、短文を一息で完成させる経験へ広げる。6分類は各160件とし、物の名前だけでなく、動き、風景、人とのやり取りを入れる。歌詞、引用文、固有の作品やキャラクター、広告文を題材にしない。

初版240件から720件を増補した。ゆったりは80→240件で3倍、ふつうは100→300件で3倍、挑戦は60→420件で7倍とし、短文の題材を厚くした。既存語の表記・読み・ID・所属・基準長は保ち、コース内の相対難度帯は全960件の構成で再計算する。

| コース | 件数 | 許容L | 実データのL | 主な内容 |
| --- | ---: | --- | --- | --- |
| ゆったり | 240 | 3〜8打鍵 | 3〜8打鍵 | 短い語。ん、促音、小書き仮名、長音記号を含めない |
| ふつう | 300 | 5〜14打鍵 | 5〜14打鍵 | 身近な語と入力要素。短い外来音も含む |
| 挑戦 | 420 | 10〜24打鍵 | 10〜24打鍵 | 意味のまとまりを持つ短文 |

表示文の実最大長は13文字、読みの実最大長は14文字である。仕様上の上限は表示18文字、読み16文字とし、実最大長を新しい制約として扱わない。ID、表示、読みはいずれも全960件で一意。

漢字とカタカナの表示には、対応するひらがなの読みを明示する。助詞の「は」「へ」「を」は表記どおりの仮名を打つ。「こんにちは」の末尾も「は」とする。長音記号「ー」は読み内に残し、入力規則のASCIIハイフンで受理する。

難度帯はコースの中で相対的に決める。基準長Lに、んの数、促音の数×2、基本拗音の数×2、外来音の数×2、長音記号の数を加えてcomplexityScoreを作り、complexityScore・L・IDの順に並べて40%を易、40%を中、20%を難へ割り当てる。同じ複雑度の語でも境界では異なる帯になり得る。実測した体感難度や所要時間を表す値ではない。

| --- | ---: | ---: | ---: |
| ゆったり | 96 | 96 | 48 |
| ふつう | 120 | 120 | 60 |
| 挑戦 | 168 | 168 | 84 |

## 3 入力要素と練習の幅

入力要素は読みから機械的に付与し、練習の検索と実績判定に共用する。1語に複数の要素が付くため、次表の件数の合計は960にならない。F03はn・sokuon・yoon・long_markの4種類を使い、foreignは練習分類として使う。

| タグ | 画面上の意味 | 含む語数 | 収録例 |
| --- | --- | ---: | --- |
| n | ん | 234 | パンダ、店員、本屋 |
| sokuon | 小さいっ | 75 | 切手、ラッコ、棚をさっと拭く |
| yoon | 小さいゃ・ゅ・ょ | 112 | 金魚、シチュー |
| long_mark | のばす音「ー」 | 63 | カーテン、ヨーグルト |
| foreign | 外来音 | 9 | カフェラテ、カフェの扉を開ける |

「のばす音」は長音記号「ー」の入力を指す。「おう」「えい」など音声上の長さを一括判定するタグではない。「店員」と「本屋」は、んの直後に母音・や行が来る場面を短い語で経験できる。「カフェラテ」は8打鍵で外来音を練習し、長文での負担と分けられる。

1本の正解ローマ字列は語データに保存しない。複数綴りを受理するグラフを読みと規則から作る。canonicalLengthは全受理経路の最短長であり、プレイヤーが選んだ長い綴りによって完成点や基準速度を増やさない。入力規則の受理表、グラフ、特殊入力は初版と同じである。

## 5 固定集合と実績・変更時の扱い

各レコードのidを収集記録・練習記録・実績の参照に使う。現在の辞書集合はkotobabin-ja-960-v2であり、各語のdictionarySetIdも同じ値を持つ。実績の必要語集合はトップレベルのcollectionSetsで別に管理する。キーが固定集合ID、値がwordIds配列である。

| 固定集合ID | 件数 | 構成 | 用途 |
| --- | ---: | --- | --- |
| kotobabin-ja-240-v1 | 240 | 初版の240ID | E04の必要集合 |
| kotobabin-ja-960-v2 | 960 | 第4版の全ID | L01・L02の件数集計、L03の必要集合 |
| kotobabin-ja-relaxed-v2 | 240 | 第4版のゆったり全ID | L04の必要集合 |
| kotobabin-ja-standard-v2 | 300 | 第4版のふつう全ID | L05の必要集合 |
| kotobabin-ja-challenge-v2 | 420 | 第4版の挑戦全ID | L06の必要集合 |

E01は異なる10語、E02は50語、E03は150語、E05は6分類の各5語を条件とし、既存語と新語の両方を数える。E04は初版240語をすべて完成した場合だけ解除し、新語で不足分を置き換えない。初版240語・未完成の絞り込みと、直接選択・順送り練習により、残る旧語へ必ず到達できる。

L01「新しい出会い」は現960語の異なる300語、L02「半分の図鑑」は480語、L03「大きな図鑑」は全960語、L04「短いことばの図鑑」はゆったり240語、L05「広がることばの図鑑」はふつう300語、L06「文の図鑑」は挑戦420語を条件とする。L系統は第4版の固定ID集合で判定し、すべてのモードのWordCompletedを対象とする。

公開後に意味の異なる語へ同じIDを使い回さず、将来の増補でも初版と第4版の固定集合を変えない。既存語のID・表示・読み・コース・分類・基準長は固定参照と照合する。相対難度帯は現在のコース内全件から再計算するため、初版から変わることがある。

reviewedは作成時の表記と読みを校正した状態を表す。独立レビューやブラウザーでの実機検証の完了をこの真偽値に兼用しない。独立レビューの指摘と反映は[レビュー履歴](review_history.md)へ記録する。

再検査は同梱フォルダーのルートで次を実行する。追加パッケージとネット接続は不要である。

```bash
python3 tools/validate_content.py
```

機械可読の報告は次の実行で得る。出題スキーマ版2.0.0と規則スキーマ版1.0.0は別に確認する。

```bash
python3 tools/validate_content.py --json --report content_check.json
```

本編の出題は技術仕様の決定的な出題計画を使い、「易・中・中・難・易」の波を作る。JSON上の並びをそのまま出題順とせず、現在の誤打や得点で順番を変えない。画面例20問は数値の参照用で、公開版の出題列を固定するデータではない。
