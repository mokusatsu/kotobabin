# ことば便 街の発展・景観詳細一覧

版4.1　2026年11月13日

6地区それぞれに段階0〜5の36状態を定める。段階1〜5の完成した姿は30枚の独立原画とし、段階0は共通更地1枚を利用する。川沿い・海辺・高原の背景3枚と合成することで、108通りの地区と景観の組み合わせを表現する。

費用と機能の正本は[経済設定](../data/economy_config.json)、地区の名称・造形・配置の正本は[街マスター](../data/city_catalog.json)。店舗・鉄道・足場の合成は[資材の実装仕様](resource_implementation.md)、個別の画像IDは[資材一覧](visual_resource_inventory.md)を参照する。

## 2 全36段階

費用はその段階へ上がるための増分である。コインは計画開始時に支払い、資材がそろうと追加待ち時間なしで完成する。次の段階は自動開始しない。段階0の費用0は初期状態の意味であり、開通費を免除する意味ではない。
