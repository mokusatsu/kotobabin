# ことば便 実績・報酬詳細一覧

版4.1　2026年11月13日

全72実績に、解除条件、対象、進捗表示、確定場面、保持規則、固有の切手図柄、称号IDを定める。各実績は切手1枚と同名の称号を自動付与する。系統と総数の節目による追加報酬は40項目あり、切手枚数へ加算しない。

ルールの全体像は[ゲーム体験仕様書](game_experience.md)、正本は[実績マスター](../data/achievement_catalog.json)、画像の制作一覧は[画像・アイコン等の資材一覧](visual_resource_inventory.md)を参照する。表示状態や合成の技術条件は[資材の実装仕様](resource_implementation.md)に分ける。

| 対象 | 進む遊び方 | 確定の扱い |
|---|---|---|
| 全 | 操作体験・練習・復習・本編・スキップを使った本編 | 成立した語や配達で確定し、途中終了でも残る |
| 練 | 練習と復習 | 成立時に確定。練習開始・未完成語の飛ばしで現在連続数をリセットする |
| 便 | 1語以上完成し90秒完走した本編。スキップ可 | 完走時に確定。各項目に追加条件があれば適用 |
| 通常 | 90秒完走し、語のスキップをしない本編 | 完走時に確定。ガイド・文字拡大・一時停止は可。H05だけガイド非表示 |
| 街 | 資材到着・建築完了・購入・再出発 | 街の成果が確定した時。本編の完走は不要 |

配達実績に数えるのは、手動配達と荷物5個の自動配達だけである。時間切れとスキップで送った分は得点へ加えるが、配達行為の回数・荷物数へ加えない。通常の実績の仮達成、現在の便の対象外、過去に獲得済みの状態を区別する。

## 5 報酬を表示する場面

プレイ中は語の境目に1件だけ、最大1.2秒の固定通知を出す。通知開始は10秒以上離し、複数の解除は件数へまとめる。通常の実績は結果で確定し、新しい切手は最大3枚を表示する。4枚以上は「ほかN枚」から手帳へまとめ、再挑戦を待たせない。

未解除の固有図は同じ彩色原画を低彩度でプレビューし、未解除の文字を添える。輪郭専用の別原画は作らない。B05とF06の条件公開前だけ共通の封筒印とヒントを示し、条件公開または獲得後に固有図へ切り替える。選択枠、目標のピン、未読の封筒印、獲得ラベルは別々の場所へ置く。

額縁4種、飾り2種、夕景パネル1種は、各種類から1つまたは「表示しない」を選ぶ。称号も1つまたは非表示にできる。アルバム・絵葉書・記念台紙は鑑賞物であり、強さや得点を変えない。
