# ことば便 制作資料

版4.1　2026年11月13日

ことば便は、日本語の語や短文を打って資材を届け、街を育てる90秒のWebタイピングゲームである。配達で建物を増やし、店舗の営業収益を荷づくり台・配送班・鉄道へ再投資する。タイピングの上達、72枚の実績切手、960語の図鑑、6地区の成長をそれぞれ確かめられる。

制作資料はゲーム体験、技術、画面、実績・発展・設備の全件一覧、資材台帳、出題一覧、検証をMarkdownへ分けて収録する。JSONは実装へ渡す正本、Pythonは入力資材と経済式を検査する参照ツールである。ブラウザーで動く製品本体は本資料に含まない。

## 2 第4.1版の詳細化

実績72件と追加報酬40項目、街の36段階、設備の全レベルを具体的な資材IDへ対応させた。必要な独立制作は画像・SVG241点（原画149点・SVG92点）と音源7点。レベル、表示状態、景観との組み合わせを別原画へ重複計上しない。全件の対応は709件のバインディングから再集計できる。

荷づくり台51状態は5外観帯、道路の配送班は4車種、研究18状態は3アイコンと目盛りで表す。未解除・仮達成・獲得・選択・目標・未読・装着を区別し、地形・地区・店舗・足場・貨物輸送の合成位置を固定した。ゲームの数値ルールと960語は第4版の内容を維持する。

個別画像・SVG・音源は発注仕様を完成した段階で、ファイル自体は制作前である。既存5画面は構成と画風の参照として保持する。

### 第4版から維持する内容

資材は完成語の基準長と確定した配達ボーナスから発生し、選んだ地区へ運ばれる。必要量が届くと建物が完成し、店舗の営業でコインが増える。荷づくり台は生成量、配送班と鉄道は輸送能力、店舗は営業収益を強化する。作る・運ぶ・稼ぐのどこを伸ばすかを選べる。

街は住宅地、商店街、工房街、公園通り、駅前、港町の6地区、各5段階で育つ。建築へ予約する資材と自由在庫を分け、計画の一時停止で鉄道化へ資材を回せる。留守の進行は既存輸送待ちと営業の最大8時間分を自動反映する。任意の再出発では設計図を得て、研究を次の街へ引き継ぐ。

設備はタイピング得点・正確率・基準速度を変更しない。従来のA〜Hの48実績を維持し、建築I・物流J・設備K・増補語彙Lの24実績を加えた。切手の報酬は絵葉書・台紙・称号等の装飾とし、機能する街の開発は資材と投資で進める。

## 3 完成した960件の出題資材

| コース | 前版 | 第4版 | 拡充倍率 | 基準長L |
|---|---:|---:|---:|---|
| ゆったり | 80 | 240 | 3倍 | 3〜8 |
| ふつう | 100 | 300 | 3倍 | 5〜14 |
| 挑戦 | 60 | 420 | 7倍 | 10〜24 |
| 合計 | 240 | 960 | 4倍 | — |

6分類は各160件で、その内訳はゆったり40・ふつう50・挑戦70。追加720件を編集し、類似場面の偏り、読み、自然な言い回しを確認した。ID・表示・読みの完全重複は0件。旧240件のID、表示、読み、コース、分類、基準長を保持している。

全体の相対順位から難度帯を再計算したため、旧240件のうち13件は帯だけが変わる。旧画面例20語のLと帯はすべて不変。旧E04の必要集合は240件で固定し、新しい全960件・コース別図鑑は別の固定集合にする。図鑑の「初版240語」「未完成」から残りの語を直接練習できる。

## 6 再検査

同梱フォルダーのルートで実行する。標準Pythonのみを使い、追加パッケージやネット接続を必要としない。

```bash
python3 tools/validate_resources.py
python3 tools/build_resource_docs.py --check
python3 tools/validate_content.py
python3 tools/economy_model.py validate
python3 tools/economy_model.py example
python3 tools/economy_model.py balance
```

出題は全960件の構造、重複、読み、最短長、タグ、難度帯、固定集合を検査する。経済は価格、生成、到着、計画完成、分割時間、放置、保存復元、同一イベント、購入制約、再出発を検査する。画面数値例は開始状態とイベント列を保持し、計算の根拠をたどれる。

仕様、全件一覧、出題、資材の発注台帳、代表画像を完成した。個別の241画像・SVGと音源7点は制作前である。ブラウザー本体、実機IME、入力遅延、文字拡大、初見のプレイ観察は実装後の受入試験として定義している。モデル上の所要時間を利用者の平均や実測の楽しさと扱わない。
