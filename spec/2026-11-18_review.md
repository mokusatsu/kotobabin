# 「ことば便」の報酬システム評価：タイピングが得意な小学2年生の視点

結論からいうと、現状の「ことば便」は、タイピングを覚え始めた子が楽しみながら上達するゲームとしてはよく設計されています。しかし、ほかのタイピングゲームの実績をほぼ集め終わった小学2年生が、半年、1年と遊び続けるゲームとしては、報酬の量も種類も不足しています。

特に大きな問題は、72個の実績を獲得したあとに、タイピングが上達しても新しく獲得できるものがほとんどなくなることです。

私がその小学2年生だったら、おそらく次のように感じます。

> 「切手をいっぱい集めるのは楽しそう。でも、全部集めたらどうなるの？　もっとすごい切手はないの？　街をもう一回作るだけじゃなくて、新しい街や特別な建物がほしい！」

現行仕様は、実績72件、追加報酬40項目、960語の図鑑、6地区の街づくり、再出発と恒久研究で構成されています。実績の条件も単なる速度だけでなく、正確さ、配達方法、練習、語彙、街の発展を評価しています。この基本方針は維持する価値があります。

## 2. 実績は最低300件、できれば500件程度を目指したい

私なら、現行の72件を単純に増やすのではなく、実績を「コレクション」「段階別の熟練度」「繰り返し更新できる記録」の3層に分けます。

推奨する実績構成

合計500件の設計例

0306090120既存実績タイピング技能語彙・図鑑街・施設配達・戦略長期・やりこみ発見・隠し

既存72件を含む。追加428件の内訳は提案値です。

500件すべてに専用画像を用意する必要はありません。例えば「速さの達人」という実績に銅・銀・金・虹・伝説の5段階を設ければ、一つの基本図柄で5件分の達成を提供できます。

ただし、500件という数字そのものを目標にするのではありません。重要なのは、達成に要する時間が異なる目標を常に用意することです。

## 3. 追加したい実績の具体例

### A. タイピングそのものが上達する実績

最優先で増やしてほしいのは、この分野です。街を育てるのも楽しいですが、自分自身のタイピングが上手になったという達成感は、ほかの報酬では代替できません。

| 実績シリーズ    | 解除条件の例                          | 段階数 |
| --------- | ------------------------------- | --- |
| 風より速い配達人  | 毎分200・225・250・275・300・350・400打  | 7   |
| ミスなしマスター  | 10・20・30・40・50・75・100語連続無誤打     | 7   |
| 正確さの王様    | 90秒、正確率98・99・100%など             | 3   |
| 自己ベスト更新   | 同一条件で自己記録を1・3・5・10・20回更新        | 5   |
| 長文マスター    | 挑戦コースで長文を10・30・50・100・200件無誤打完成 | 5   |
| スピードと正確さ  | 毎分200・250・300・350打かつ正確率98%以上    | 4   |
| 読みだけチャレンジ | ガイド非表示で10・30・50・100語完成          | 4   |
| 苦手なキーを克服  | 苦手キー群の正確率を一定以上改善                | 5   |

これらの数値は難度調整前の案です。毎分打鍵数はコースや問題の長さで変わるため、十分な出題量と適格条件を設定する必要があります。

さらに、単純な速度実績以外にも、実際の上達を評価したいです。例えば「先月より正確率が3ポイント上昇」「難しい語の成功率が80%を超えた」といった成果なら、すでに速い子にも成長の余地があります。

### C. 街の発展と結びついた実績

### D. 配達の工夫を楽しむ実績

ことば便の特徴は、完成した荷物を早めに届けるか、5個までためてボーナスを狙うかという判断です。

この部分も、1回成功したら終わる実績ではもったいないです。

| 実績名     | 条件の例                            |
| ------- | ------------------------------- |
| まとめ便の職人 | 5個の自動配達を累計10・50・100・500回        |
| ぴったり配達  | 荷物4個で手動配達を累計10・50・100回          |
| お届け名人   | 1便中に1・2・3・4個の手動配達と5個の自動配達をすべて成功 |
| 連続満載便   | 5個の自動配達を連続2・3・5回成功              |
| 配達の計画家  | 同じ問題順で自己最高スコアを複数回更新             |
| 完ぺきな配送  | 1便で誤打なし、かつ5個の自動配達を複数回成功         |

上級者にとって面白いのは、単に手が速いだけでは獲得できない実績です。「どこでSpaceを押すか」を考えることで達成できる実績があると、タイピングの上達が頭打ちになっても遊ぶ理由ができます。

## 4. 「実績を全部集めた後」の仕組みが必要

私は、ここを最も重視します。

仮に実績を500件に増やしても、500件すべて獲得すれば再びやることがなくなります。したがって、一定数の実績は継続的に更新できる必要があります。

繰り返し達成に意味がある実績だけを対象とする例。初回限定の実績や図鑑コンプリートには別の進行条件を設定します。

さらに、伝説を獲得した後にも「伝説★1、★2、★3……」のような名誉ランクを増やせば、到達点を完全に固定しなくて済みます。

ただし、永久に同じ条件を繰り返させるだけでは、遊びというより作業になります。そのため、名誉ランクは補助的な報酬とし、新しい挑戦も並行して用意すべきです。

## 5. 実績以外の報酬にも変化が必要

タイピングが得意な子にとっては、何度も練習する理由よりも、練習すると何が起こるかが重要です。

特に、次の4種類の報酬を充実させたいです。

| 報酬    | 具体例                  | 私がほしい理由          |
| ----- | -------------------- | ---------------- |
| 切手    | 珍しい切手、虹色切手、特別シリーズ    | まだ持っていないものを集めたい  |
| 称号    | 超速配達人、伝説の郵便屋さん       | 自分がどれだけすごいか見せたい  |
| 街の装飾  | 特別な駅舎、列車、建物、公園       | 自分だけの街を作りたい      |
| 記録の展示 | 歴代最高速度、無誤打記録、挑戦達成記念碑 | 頑張ってきた記録をいつでも見たい |

なかでも、私は「街に実績記念碑が建つ」仕組みがほしいです。

自分の成果が街に永久に残るなら、たとえすべての実績を集めても、自分だけの街を完成させたいという気持ちが続きます。

## 6. 毎日遊べるチャレンジがほしい

現行仕様では、ログイン日数や連続日数を実績条件にしない方針です。この点には賛成します。

しかし、毎回同じ90秒の配達だけでは飽きる可能性があります。曜日や日付で挑戦内容が変わる、任意のチャレンジモードがあるとよいと思います。

例えば「今日は動物の言葉だけ」「長い言葉を正確に打とう」「荷物を5個まとめて3回届けよう」といった内容です。

これらには小さな報酬を用意し、参加できなかった日があっても不利にならないようにします。チャレンジの種類が循環しても、自己ベストや達成履歴は残る設計にします。

また、最高記録に近い目標を自動提案する仕組みも有効だと思います。毎分180打の子に毎分400打を要求するのではなく、まず毎分190打に挑戦させることで、実績収集を継続的な成長につなげられます。

## 7. 逆に増やすべきではない実績

実績数を増やすこと自体が目的になると、かえって面白くなくなります。特に次の条件は避けるべきです。

- 毎日ログインしないと途切れる実績
- 故意にミスをすることが達成条件の実績
- 同じ短い語を何千回も繰り返すだけの実績
- 長時間プレイしないと達成できない日次ノルマ
- 入力ガイドや補助設定を使っていると一律に不利になる実績
- 放置しているだけで大量に獲得できる実績

ゲームを長く続けてもらうことと、長時間遊ばせることは別です。

1日10分しか遊ばなくても数か月後には立派な街になり、自分が上達したことを確認できる仕組みが理想だと思います。

## 8. 優先順位と具体的な拡張計画

実装の優先順位は、次のように考えます。

| 優先度 | 追加内容           | 理由                 |
| --- | -------------- | ------------------ |
| 最優先 | タイピング技能の多段階実績  | 上級者にとって即座に新しい目標になる |
| 最優先 | 語ごとの熟練度        | 960語という既存資産を活用できる  |
| 高   | 実績切手のランクアップ    | 一度達成して終わる問題を解消できる  |
| 高   | 6地区・設備・鉄道の詳細実績 | 街づくりの目標を大幅に増やせる    |
| 高   | 実績による街の装飾      | 報酬に目に見える価値を与えられる   |
| 中   | 変化するチャレンジ      | 毎回のプレイに新鮮さを与えられる   |
| 中   | 記念碑・記録展示室      | 過去の達成感をいつでも振り返れる   |
| 中   | 隠し実績と特殊条件      | 新しい遊び方を発見する楽しさを作れる |

設計上は、まず既存72件を残したまま追加428件を定義し、合計500件規模へ拡張するのがよいと思います。ただし、一斉に500枚分の絵を制作するのではなく、共通の絵柄と段階表示を使って、報酬体系を効率的に増やす方式を推奨します。

## 最終評価

私がタイピングの得意な小学2年生だったら、現在の「ことば便」は、最初の数日から数週間は楽しめると思います。ただし、その後も長く遊び続けるかというと、現状の実績72件だけでは少し難しいと感じます。

一方で、タイピングの成長、960語の収集、街の発展、設備の強化という4つの進行要素があるため、報酬システムを拡充する基盤は十分にあります。

最も大切なのは、実績をただ増やすのではなく、次の3つを同時に成立させることです。

1. 今日遊んだら、何か一つは達成できた。
2. 来週遊んだら、新しい目標に挑戦できる。
3. 半年後に遊んでも、まだ手に入れていないものがある。

特に「切手の段階的な成長」「960語それぞれの熟練度」「実績で飾れる自分だけの街」を組み合わせることが、ほかのタイピングゲームを遊び尽くした子にとって、ことば便を長く楽しめるゲームにするための重要な改善だと考えます。

現行の仕様書でも、実績の役割は`ゲームに別の見方を与える目標`と説明されています。
