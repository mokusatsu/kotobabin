# 通常便・追加便の実績と切手の改定案

積み荷が5個になった時点で通常便を発送する。ミスなしの連続5問目から、ミスをするまで毎問追加便を発送する。ミスなしで連続10問を完成した場合は、5〜10問目に1回ずつ追加便が出る。同じ問題を完成したときに両方が成立すれば、通常便・追加便を各1回と数える。荷物の累計には発送した実荷物を一度だけ加える。

1問で誤打した位置が0〜1か所なら荷物を積み、2か所以上ならその問題の荷物は積まない。同じ入力位置での誤打は、何回繰り返しても積載判定では1か所と数える。最初の誤打でミスなしの連続記録は途切れる。たとえば4問をミスなしで完成した後、5問目を1か所の誤打で完成した場合は、通常便1回、追加便0回となる。

通常便のボーナスは積んだ5問の基本点の合計とする。追加便は連続5問目にその5問の基本点の合計、6問目以降は完成した1問の基本点を加える。両方が出た場合はボーナスも両方加わる。追加便までの進捗は5つの印で示し、成功ごとに印を灯す。5つそろった状態は連続が続く間表示し、誤打した時点で印をすべて消す。

荷物は各段階の荷台中央に降り、5個目は満載の一番上の包みの中心に重なる。通常便の出発演出は荷物が着いてから動き出す。追加便も貨車を牽引して出発する。

## 固定実績

表のA系はチュートリアル・練習を含めて成立時に確定する。B系・H系はスキップなしで90秒を完走した本編を対象とする。時刻条件は本編の残り時間と同じ時計を使う。

| ID | 新しい条件 | 切手絵 |
| --- | --- | --- |
| A02 はじめてのお届け | 通常便を初めて1回発送する。 | 再利用。郵便受けへの最初のお届け。 |
| A03 まとめて出発 | 通常便を累計2回発送する。複数のプレイにまたがってよい。 | 再利用。荷物をまとめた台車。 |
| A04 はじめての追加便 | 追加便を初めて1回発送する。 | 再利用。旗の付いた荷車。 |
| B01 前半のお届け | 開始45秒以内に通常便を1回発送する。 | Invalidate。戸口での1個の手渡しを、道を走る通常便の荷車に差し替える。 |
| B02 ふくらんだ荷物 | 同じ本編で追加便を2回以上発送する。 | 再利用。荷物が詰まった布包み。 |
| B04 ふたつの出発 | 同じ問題の完成で通常便と追加便を同時に発送する。 | 再利用。二方向に分かれる配送路。 |
| B05 送り出して、もう一便 | 通常便の発送直後の5問をミスなしで完成し、その5問の間に追加便を1回以上発送する。 | Invalidate。大小の荷車の対比を、先行する通常便と後続の追加便に差し替える。 |
| B06 出発のあと一問 | 通常便を発送した直後の問題をミスなしで完成する。 | Invalidate。4個の手動便を表す受け渡し台を、満載便と次のことばを表す構図に差し替える。 |
| H04 三つの道へ届ける | 3コースそれぞれで、同じ問題の完成による通常便・追加便の同時発送を記録して本編を完走する。 | 再利用。三方向へ送り出す仕分け台。 |

B03とH03は通常便の発送回数で判定する。G04とG05は通常便で届けた荷物の累計を新たに加算する。過去に手動便で届けた荷物数は累計に保持する。

チュートリアルを最初の5問ミスなしで終えた場合は、A01・A02・A04の3枚とA系の絵葉書を獲得する。通常便だけでチュートリアルを進めた場合は、獲得済みの切手を表示し、絵葉書はA系3枚に達した時点で授与する。

## シリーズと秘密の切手

対象はスキップなしで90秒を完走した本編とする。

| 既存の識別子 | 新しい条件 | 切手絵 |
| --- | --- | --- |
| `manual_1` | 全コース合計で追加便を累計1・3・10・30・100回発送する。 | 5枚を再利用。 |
| `manual_2` | ゆったりで追加便を累計1・3・10・30・100回発送する。 | 5枚を再利用。 |
| `manual_3` | ふつうで追加便を累計1・3・10・30・100回発送する。 | 5枚を再利用。 |
| `manual_4` | 挑戦で追加便を累計1・3・10・30・100回発送する。 | 5枚を再利用。 |
| `all_sizes` お届け名人 | 同じ本編で通常便・追加便を各2回以上発送する。 | 再利用。戸口にそろった荷物。 |
| `small_steps` 小さな階段 | 同じ本編で追加便を30秒以内に1回、60秒以内に累計2回、終了までに累計3回発送する。 | 再利用。橋の上に並ぶ3段階の小包。 |
| `back_steps` 折り返しのお届け | 前半45秒と後半45秒のそれぞれで、通常便・追加便を各1回以上発送する。 | Invalidate。4・3・2・1個の順序を表す階段を、前半と後半のお届けを表す構図に差し替える。 |
| `two_baskets` ふたつのかご | 通常便・追加便の同時発送を同じ本編で2回以上記録する。 | 再利用。対になる二つのかご。 |
| `between_full` 真ん中の追加便 | 同じ本編で通常便を3回以上発送し、2回目の通常便と追加便が同時に出る。 | Invalidate。満載車の間にある1個の小包を、真ん中の通常便と一緒に出る追加便に差し替える。 |
| `first_twenty_by_four` 二十問のお届け | 最初の20問をミスなしで完成し、5・10・15・20問目の追加便を記録する。 | 5・10・15・20問目を表す4台の貨車。 |

通常便の累計・連続・ミスなし完走での発送を扱う既存シリーズは、通常便の発送だけで判定する。連続満載便は、通常便を5問おきに発送した回数で判定する。地区別・全体の荷物累計は、現行どおり通常便と終了時の端数便などの実荷物を数える。

既存の切手IDと獲得済みの記録を保持する。追加便の新しい累計は切り替え時点から記録し、旧手動便の回数は引き継がない。再生成の対象とファイル名は[アセット制作進捗](../docs/development/asset_progress.md#配送実績の改定に伴う再生成対象)に記載する。
